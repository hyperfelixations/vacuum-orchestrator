# Vacuum Orchestrator

Vacuum Orchestrator is a planned custom integration for Home Assistant. Its
goal is to provide manufacturer-neutral job and queue orchestration for one or
more robot vacuums through the Home Assistant integrations that already manage
those devices.

Planned capabilities include persistent cleaning jobs, queue control,
configurable readiness conditions, vacuum-before-mop dependencies, multi-robot
assignment, and manufacturer-specific adapters. Roborock is the first intended
adapter; the orchestration core is designed to remain vendor-neutral.

## Project status

This repository is an initial project scaffold. It does not contain an
installable Home Assistant integration or a release yet. Installation and
configuration instructions will be added when a tested preview is available.
